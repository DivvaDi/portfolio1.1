## 📱 Mobile First

Вёрстка выполнена по принципу **Mobile First**: базовые стили рассчитаны
на мобильные экраны (320–480px), затем через `@media (min-width: 640px)`
и `@media (min-width: 900px)` добавляются планшетная и десктопная раскладки.
Также адаптированы размеры шрифтов через `clamp()`.

## ✨ Реализованный JavaScript

1. **Переключатель тёмной/светлой темы** — с сохранением выбора в `localStorage`
   и реакцией на системную тему (`prefers-color-scheme`).
2. **Кнопка «Наверх»** — появляется после прокрутки 400px, плавно возвращает к началу.
3. **Плавная навигация по якорям** — с учётом высоты «липкого» хедера
   и авто-закрытием мобильного меню.

**Дополнительно:**
- Прогресс-бар чтения страницы
- Reveal-анимации при скролле (`IntersectionObserver`)

- Мобильное бургер-меню
- Автоподстановка текущего года в футере

## 🤖 Использование AI-помощника

**Инструмент:** DeepSeek
**Задача:** генерация структуры одностраничника и помощь с вёрсткой
CSS Grid для блока «Проекты» и адаптивных медиазапросов.

**Существенный промпт:**
> «Помоги спроектировать одностраничный сайт-портфолио флориста
> в барочно-модерновом стиле: тёплая палитра, винный акцент, тёмная
> и светлая темы. Нужны секции Hero, Обо мне, Опыт, Образование,
> Навыки, Проекты, Контакты. Подход Mobile First. Предложи разметку
> и структуру CSS-переменных для двух тем.»

**Что дала нейросеть:**
- базовую структуру секций и общий каркас разметки;
- набор CSS-переменных для двух тем;
- подход с сеткой карточек.

**Что пришлось проверить и исправить самостоятельно:**
- сочетание оттенков — контраст текста на кремовом фоне был
  недостаточным, я затемнила `--text` и подобрала тёплый тёмный
  вместо чистого чёрного;
- форму «фото-рамки» под портрет — заменила жёсткий круг
  на асимметричный `border-radius`, чтобы выглядело по-барочному;
- логику переключателя темы — добавила реакцию на смену системной
  темы через `matchMedia`, если пользователь ещё не сделал свой выбор;
- фильтрацию проектов — проверила поведение при пустой категории
  и добавила сообщение «В этой категории пока нет проектов»;
- контент: нейросеть не могла знать фактов обо мне, поэтому
  весь текст написан мной на основе реальной биографии.

**Время выполнения:** ≈ 1 час (с учётом правок и наполнения).
